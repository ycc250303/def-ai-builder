# App 页面文档

## 页面通用规则

App采用 `app/assets/PlantMate/` 中V12花园、V4社交、V3个人中心的像素风格。角色与地图使用独立图片分层绘制；社交与个人中心使用浅色卡片。界面通过Flutter ARB提供简体中文和英文，默认跟随系统，也可在设置中切换并保存。昵称、评论与动态正文保留用户原文。

一个账号支持多株植物，每株植物拥有独立花园和一只宠物。植物选择切换对应花园、宠物、成长日记、环境记录、设备和参观权限。移除植物后保留宠物与成长记录，植物管理页面支持重新绑定。

环境监测、设备、社区与参观审批均采用本机模拟。状态与操作记录在重新打开后恢复。五种行为评分、资格、冷却和时间间隔见[需求文档](需求文档.md)。素材中15秒轮播用于动画演示，业务行为继续遵循需求规则。

## 一、养育首页

| 页面区域 | 展示与交互 |
| --- | --- |
| 顶部 | 当前花园与植物选择、模拟设备状态、场景调整入口 |
| 花园 | 分层像素地图、Tuantuan、对应宠物、装饰和自动行为动画；点击场景进入全屏 |
| 行为状态 | 自动显示喂食、清洁、玩耍、探索或睡觉；没有行动时显示陪伴状态 |
| 宠物信息 | 昵称、等级、四项状态和当前等级的成长经验 |
| 最新事件 | 最近行动、升级或进化记录 |
| 全屏入口 | 场景内提供独立的全屏按钮 |
| 底部导航 | 花园、社交、我的 |

点击场景或全屏按钮进入全屏花园，提供退出按钮与返回操作。五种行为自主执行；探索时植物离开、宠物留在花园。进化后使用新的形象播放相应行为动画。

场景调整入口打开全屏编辑页面。用户切换“浏览地图”拖动与缩放到目标区域，再切换“调整装饰”拖动装饰改变位置，点击装饰选择替换或收起；通过“恢复已收起的装饰”恢复显示。保存后返回首页，场景位置与显示状态保存到当前花园。花园区域固定，装饰位置限制在地图范围内。

## 二、社交页面

| 页面 | 功能与交互 |
| --- | --- |
| 推荐 | 单列大卡片显示作者、正文、App生成的图片及互动入口；点击进入详情 |
| 关注 | 使用相同卡片展示已关注用户的帖子 |
| 搜索 | 搜索昵称、固定账号、简介、花园与帖子；展示用户、花园和动态结果 |
| 通知 | 点赞、评论、关注通知与花园参观申请；支持全部已读 |
| 帖子详情 | 完整正文与图片、点赞、评论、回复、收藏及花园参观入口 |
| 发布动态 | 选择花园和图片类型，填写可选标题与必填正文；可关闭图片发布纯文字 |
| 内容管理 | 用户可以编辑、删除自己的帖子，回复评论及删除自己的评论 |
| 用户主页 | 头像、昵称、简介、固定账号、花园与公开帖子，支持关注用户 |
| 我的收藏 | 展示已收藏帖子，点击查看详情 |
| 花园参观 | 权限检查通过后展示花园；支持拖动与缩放，保持只读 |

顶部设置“推荐”“关注”两个分类、常驻搜索入口与通知按钮；右下角提供发布按钮。动态图片来自App渲染的花园、宠物或探索成果。Demo不提供自由上传与跨应用分享。

删除帖子或评论前展示确认提示。公开帖子不会修改花园的参观权限。点赞、关注、评论和收藏不会改变养育数值。从参观或详情返回时，回到之前页面，保留原页面的浏览状态。

### 花园参观权限

| 权限 | 进入条件 |
| --- | --- |
| 完全开放 | 所有用户直接进入 |
| 需要申请 | 访客提交申请，主人批准后进入；拒绝后可以重新申请 |
| 不开放 | 其他用户不能进入 |
| 向我关注的人开放 | 主人关注访客 |
| 向互相关注的人开放 | 主人与访客互相关注 |
| 向我的粉丝开放 | 访客关注主人 |

每座花园独立选择一项权限。帖子公开、用户关注和花园访问分别判断，不设置宠物资料或成长记录的独立公开开关。允许参观时公开主页直接展示花园画面；不具备访问资格时显示权限说明。

“需要申请”的花园支持申请去重、等待、批准、拒绝和重新申请。主人在通知页处理收到的申请；发出的申请提供“模拟主人批准/拒绝”入口，明确标记本机演示。个人中心权限页可以生成预置访客申请，体验主人审批流程。权限变更会终止此前授权；移除植物后关闭花园访问。

访客只能观察场景，不能修改装饰或执行养育行为。公开场景不包含设备、原始传感器记录及四项养育数值。

## 三、我的页面

| 页面 | 功能与交互 |
| --- | --- |
| 我的首页 | 个人资料、植物与宠物双卡片、进化图鉴、成长日记及管理入口 |
| 个人资料 | 修改头像、昵称与简介，查看固定账号，预览公开主页 |
| 我的植物 | 绑定、移除和重新绑定植物，修改植物昵称，查看对应宠物与监测 |
| 我的宠物 | 当前形象、等级、四项属性、经验、固定初始特征和昵称编辑 |
| 进化图鉴 | 展示该宠物已经经历的初始、第二与成熟形态及等级和时间 |
| 成长日记 | 按全部、行动、升级与进化筛选；查看依据、数值变化并发布成长记录 |
| 植物监测 | 四项模拟环境指标；切换今天与近七天曲线，点击曲线查看记录 |
| 设备管理 | 模拟绑定、解除绑定、同步环境数据与校准说明 |
| 花园参观权限 | 按花园设置六种访问规则，并模拟访客申请 |
| 我的收藏 | 查看已收藏的帖子 |
| 设置 | 简体中文、英文、跟随系统、通知偏好、账号说明、帮助和产品信息 |

绑定植物后系统分配固定初始宠物，用户可取名和改名。初始特征只供查看。每100经验升级，5级固定进化，10级随机进入七种成熟形态之一，成熟后继续升级；普通升级仅记录等级变化。宠物昵称贯穿整个成长过程。

## 四、素材目录与维护

`app/assets/PlantMate/` 保留用户交接原件，不修改、不移动其中内容。`app/assets/plant_mate/` 保存Flutter运行素材，使用小写英文目录及有含义的文件名：

- `characters/`：虚拟植物。
- `pets/`：初始、固定第二形态及七种成熟形态。
- `decorations/`：地图装饰与探索奖励。
- `effects/`：食物、泡泡和睡眠眼罩。
- `map/layout.json`：675×1292地图中的道路、水域和独立装饰坐标。
- `manifest.json`：每个文件的原始来源与SHA-256校验值，不作为图片打包。

在仓库根目录执行 `python3 app/tool/prepare_plant_mate_assets.py` 可重新生成运行素材。脚本复制原始PNG并提取共享SVG中已有的PNG，保留透明背景；Flutter使用最近邻采样显示像素图。原始HTML、截图和说明不加入运行资源。

中英文界面文案分别位于 `app/lib/l10n/app_zh.arb` 和 `app_en.arb`，通过 `flutter gen-l10n` 生成本地化代码。新增界面文案须同时提供两种语言。
