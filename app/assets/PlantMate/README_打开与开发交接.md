# Plant Mate — V12 首页＋社交＋我的三页面完整整合包

## 一、打开方式

**最便捷：** 双击根目录 `PlantMate_V12_完整三页面_离线单文件.html`，即可在 Chrome / Edge 打开三页面，无需联网、解压素材路径或后端服务。

**开发版：** 解压后打开 `网页/index.html`。开发版将 HTML、组件适配层、共享艺术素材拆分，建议在 `网页/` 目录运行 `python -m http.server 8000`，再浏览 `http://localhost:8000/index.html`。浏览器直接打开 file:// 路径时可能因跨文件安全策略无法从宿主读取 iframe 内数据，因此实际开发请使用本地 HTTP 服务；不影响单文件离线版。

## 二、唯一权威：V12 首页未改动

- `网页/pages/01_Garden_V12_original.html` 与用户上传 ZIP 中 `site/PlantMate_V12_Standalone.html` **逐字节相同**（SHA-256 可查）。
- 原有首页、地图独立层、五行为动画、每 15 秒演示切换、EXPLORE 蘑菇奖励、UFO 移动、弹窗、地图编辑与导出等全部沿用 V12，未另外重写。
- 同时提供原始可维护版 `原始素材/V12_原始开发源码_可单独运行/PlantMate_V12_Development.html` 和其 `assets/png`。

## 三、整合数据与功能

- 页面二、三只读取 V12 的实时宠物数据：Food、Mood、Energy、Clean、XP、Level、当前五行为及最新事件。
- **V12 初值：** Food 45、Mood 50、Energy 73、Clean 65、XP 12/100、Lv.1；后续完全按 V12 的计算结果变化。
- **五种行为：** Feeding、Cleaning、Playing、Exploring、Resting；每 15 秒演示切换，实际数值变动取决于 V12 自身结算，不是社交/个人模块独立增加或重复发放奖励。
- 花园截图在社交/个人模块中由 V12 地图的原始背景色、道路/水系、独立装饰图层实时合成。地图还会包含正在移动的 UFO、探索收获的装饰等；每个展示花园仅叠加一株 Tuantuan＋一只宠物，蓝色小狗属于装饰。
- 社交保持推荐、关注、搜索、帖子、参观花园、个人主页、发布预览与通知；收藏结果共享给“我的收藏”。
- 个人中心保持我的植物、我的宠物、成长日记、图鉴、收藏、设备、资料与权限。**不添加 Decorations、Achievements、初始特征或新的花园布置入口**。
- 社交发布/收藏/评论、隐私选项为本地演示，未接入真实数据库；浏览器刷新后会重置。V12 行为源仍为模拟数据，不代表已接入实机传感器或 LLM。

## 四、与此前产品概念的差别（避免混淆）

- 页面一 V12 的图鉴固定为 “2 / 9 unlocked”（Baybi、Eggie），而 V12 本身尚无 Lv.5 / Lv.10 的形态自动切换逻辑。页面三同步遵守这个**实际行为**，不会自行生成“已进化”的显示。
- 页面一中的宠物文本名称固定为 Eggie，因此页面三不会提供一个与首页不一致的独立宠物改名结果。修改昵称可通过“我的个人资料”调用 V12 自带的花园改名操作；虚拟植物仍是 Tuantuan，不存在等级。
- 页面三不再展示旧版虚构的 720 lux / 42% 土壤湿度等静态传感器数值，因为 V12 没有提供这组数据。
- **页面一原本就包含的地图图层编辑功能没有删除**，因为本次明确要求不调整页面一；页面三也不会重复建设编辑页。
