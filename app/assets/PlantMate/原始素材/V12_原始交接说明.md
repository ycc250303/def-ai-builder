# Plant Mate V12 — 开发交接（仅修复本次指定事项）

## 打开方式

- `site/PlantMate_V12_Standalone.html`：无需任何其他文件，Chrome 直接打开。所需 PNG 全部内嵌。
- `site/PlantMate_V12_Development.html`：开发可维护版本。需要保持 `site/assets/png/` 文件夹，Chrome 打开后所有图片走相对路径。**请解压完整目录，不要只复制 HTML。**
- `asset_manifest.json`：列出所有在本次 HTML 实际使用的独立 PNG、像素尺寸、用途、SHA256 和复用位置。
- `source_files/original_svg/`：原始地图素材 ZIP 中的 SVG，未经改动；和当前页面使用的 PNG 不一定是一一对应关系。部分 SVG 包含嵌入式位图，不能直接认为它们是路径可编辑 SVG。
- `source_files/references/`：用户提供的眼罩源图、抠图后素材和先前确认的地图底图参考。
- `map_manifest_reference.json`：之前版本的参考位置清单；如有出入，以 HTML 内的实时元素坐标为准。

- Feeding / Cleaning / Playing / Exploring / Resting 5 个自主行为，每 15 秒切换。
